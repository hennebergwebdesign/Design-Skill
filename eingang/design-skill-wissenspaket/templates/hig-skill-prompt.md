# Regelwerk als Skill (Video 5, Trick 20)

```
Lies die Apple Human Interface Guidelines (offizielle Seite) und erstelle daraus einen Skill "apple-hig" mit den Regeln für Layout, Typografie, Tap Targets, Farbe, Navigation. Der Skill prüft App oder UI Screens gegen diese Regeln und nennt Verstöße mit Fix. Quelle und Abrufdatum im Skill vermerken.
```

Gleiches Muster für andere Regelwerke: WCAG 2.2 (Barrierefreiheit), Google Developer Documentation Style Guide (Technische Texte).
