# Tweaks Panel Skill (Video 5, Trick 23)

```
Erstelle einen Skill "tweaks". Er fügt jeder HTML oder Astro Seite ein Slider Panel hinzu für: Schriftgrößen, Zeilenhöhe, Abstände (Sektions Padding), Farben (Design Tokens), Eckenradius. Das Panel schreibt nur CSS Variablen. Mit einem Button "Übernehmen" werden die Werte in die Token Datei des Projekts geschrieben und das Panel wieder entfernt. Das Panel darf nie in den Produktions Build gelangen.
```
