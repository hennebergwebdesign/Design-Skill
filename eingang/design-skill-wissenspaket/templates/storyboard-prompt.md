# Storyboard vor Animation (Video 3, Level 2)

```
Erstelle für [Seite oder Video] zuerst ein Storyboard, noch ohne Animation. Pro Szene oder Scroll Stufe: ein statischer HTML Frame mit Screenshot, eine Beschreibung der geplanten Bewegung (Kamera, Übergang, Timing), die Dauer. Kein Rendering, kein GSAP Code, bevor ich Feedback gegeben habe.

Feedback kommt je Frame mit ID und Position. Sammle meine Kommentare, setze sie um und liefere erst dann die Animation (GSAP, ScrollTrigger, prefers-reduced-motion beachten).
```
