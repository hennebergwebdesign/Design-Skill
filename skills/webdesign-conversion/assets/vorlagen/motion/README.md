# Mikrobewegung

| Datei | Wofür |
|---|---|
| `motion.css` | Anheben, Drücken, Staffelung, Fokusring, Block für reduzierte Bewegung |
| `count-up.js` | Zahl zählt einmal hoch, Endzahl steht im HTML |

Regeln und Schranken: `47-claude-design-hacks.md`, Abschnitt 7. Beide Dateien gehören in ein Kundenprojekt,
nicht in die Auslieferung des Plugins. Die Zahlen, die hochzählen, müssen **echt** sein
(`SKILL.md`, harte Grenze zu erfundenen Belegen).
